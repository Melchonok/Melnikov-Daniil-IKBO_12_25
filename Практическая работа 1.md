## Задача 6

Написать программу для проверки наличия комментария в первой строке файлов с расширением c, js и py.

Код скрипта check
```
#!/bin/bash

for file in *.c *.js *.py
do
    [ -f "$file" ] || continue

    case "$file" in
        *.py) pattern='^[[:space:]]*#' ;;
        *) pattern='^[[:space:]]*(//|/\*)' ;;
    esac

    if head -n 1 "$file" | grep -qE "$pattern"
    then
        echo "$file: комментарий есть"
    else
        echo "$file: комментария нет"
    fi
done
```

Создание и отработка скрипта
```
pc@Melchansky:/mnt/c/Users/PC$ nano check
pc@Melchansky:/mnt/c/Users/PC$ chmod +x check
pc@Melchansky:/mnt/c/Users/PC$ printf '// комментарий\n' > test.c
printf 'console.log("Привет");\n' > test.js
printf '# комментарий\n' > test.py
pc@Melchansky:/mnt/c/Users/PC$ ./check
test.c: комментарий есть
test.js: комментария нет
test.py: комментарий есть
```

Код скрипта duplicates
```
#!/bin/bash

find "${1:-.}" -type f -exec sha256sum {} + | sort | uniq -w 64 -D
```



## Задача 8

Написать программу, которая находит все файлы в данном каталоге с расширением, указанным в качестве аргумента и архивирует все эти файлы в архив tar.

Код создания, обработки, архивации и вывода работы скрипта
```
pc@Melchansky:/mnt/c/Users/PC$ nano pack
pc@Melchansky:/mnt/c/Users/PC$ chmod +x pack
pc@Melchansky:/mnt/c/Users/PC$ mkdir test_pack
pc@Melchansky:/mnt/c/Users/PC$ cd test_pack
pc@Melchansky:/mnt/c/Users/PC/test_pack$ echo "Первый файл" > one.txt
echo "Второй файл" > two.txt
echo "Другой тип файла" > other.py
pc@Melchansky:/mnt/c/Users/PC/test_pack$ ../pack
Укажи расширение: ../pack txt
pc@Melchansky:/mnt/c/Users/PC/test_pack$ ../pack txt
./one.txt
./two.txt
pc@Melchansky:/mnt/c/Users/PC/test_pack$ tar -tf archive.tar
./one.txt
./two.txt
```

Код скрипта bash
```
#!/bin/bash

if [ -z "$1" ]
then
    echo "Укажи расширение: $0 txt"
    exit 1
fi

find . -maxdepth 1 -type f -name "*.$1" ! -name "archive.tar" -print0 |
    tar --null -cvf archive.tar --files-from=-
```



## Задача 9

Написать программу, которая заменяет в файле последовательности из 4 пробелов на символ табуляции. Входной и выходной файлы задаются аргументами.


Код создания, обработки и вывода работы скрипта
```
pc@Melchansky:/mnt/c/Users/PC/test_pack$ nano spaces
pc@Melchansky:/mnt/c/Users/PC/test_pack$ chmod +x spaces
pc@Melchansky:/mnt/c/Users/PC/test_pack$ printf 'A    B    C\nD        E\n' > input.txt
pc@Melchansky:/mnt/c/Users/PC/test_pack$ ./spaces input.txt output.txt
pc@Melchansky:/mnt/c/Users/PC/test_pack$ cat -T output.txt
A^IB^IC
D^I^IE
```

Код скрипта
```
#!/bin/bash

if [ "$#" -ne 2 ]
then
    echo "Использование: $0 входной_файл выходной_файл"
    exit 1
fi

if [ "$1" = "$2" ]
then
    echo "Укажи разные входной и выходной файлы"
    exit 1
fi

sed 's/    /\t/g' "$1" > "$2"
```

## Задача 10

Написать программу, которая выводит названия всех пустых текстовых файлов в указанной директории. Директория передается в программу параметром. 

Код создания, обработки и вывода работы скрипта
```
pc@Melchansky:/mnt/c/Users/PC/test_pack$ nano empty
pc@Melchansky:/mnt/c/Users/PC/test_pack$ chmod +x empty
pc@Melchansky:/mnt/c/Users/PC/test_pack$ mkdir test_empty
pc@Melchansky:/mnt/c/Users/PC/test_pack$ touch test_empty/one.txt test_empty/two.txt
echo "Привет" > test_empty/three.txt
touch test_empty/other.py
pc@Melchansky:/mnt/c/Users/PC/test_pack$ ./empty test_empty
one.txt
two.txt
```

Код скрипта
```
#!/bin/bash

if [ "$#" -ne 1 ]
then
    echo "Использование: $0 директория"
    exit 1
fi

if [ ! -d "$1" ]
then
    echo "Такой директории нет"
    exit 1
fi

find "$1" -maxdepth 1 -type f -name "*.txt" -empty -printf '%f\n'
```
